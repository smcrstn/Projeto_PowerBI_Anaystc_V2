# Projeto_PowerBI_Anaystc_V2
Dashboard de Vendas e Lucro desenvolvido no Power BI utilizando a base Financial Sample. Focado em UX/UI, o projeto traz um layout clean otimizado para telas compactas, com menu de navegação lateral fixo e dinâmico, gráficos adaptados para melhor legibilidade de dados e segmentação temporal avançada. Foco total em usabilidade corporativa.
